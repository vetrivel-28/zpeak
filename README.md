# Meeting Knowledge Assistant

AI-powered meeting transcript analyzer that detects technical terms, corporate jargon, and DevOps concepts.

## Features

* SQLite Knowledge Base
* Regex Fast Detection
* Alias Detection
* Local Qwen LLM Support
* Auto Learning
* Corporate Jargon Recognition
* Multi-word Phrase Detection
* Streamlit UI
* Sub-3 Second Response Time

## Tech Stack

* Python
* SQLite
* Streamlit
* Ollama
* Qwen
* Regex NLP

## Run Instructions

```bash
pip install -r requirements.txt
streamlit run app.py
```
